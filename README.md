# SDU Lost & Found

Бюро находок для студентов. Пользователи публикуют пропажи и находки, подают заявки на возврат и рассматривают заявки на свои объявления.

## Запуск

Нужен Node.js 22.11 или новее.

```sh
npm install
npm start
```

Откройте http://127.0.0.1:3000. При первом запуске создаётся база `data/app.sqlite`.

## Демонстрация

```sh
npm run demo
```

Демо использует отдельную базу `data/demo.sqlite`. Пароль обоих демонстрационных аккаунтов — `campus-demo-2026`.

1. Войдите как `finder@example.test` и опубликуйте находку.
2. В другом профиле браузера или после выхода войдите как `owner@example.test`. Откройте находку и подайте заявку с отличительными признаками.
3. Вернитесь в аккаунт автора и подтвердите заявку на вкладке «Заявки». Объявление закроется, остальные ожидающие заявки будут отклонены.
4. Проверьте статус в аккаунте заявителя. Объявления и заявки сохраняются после перезапуска. Сессии хранятся в памяти сервера, поэтому после перезапуска нужно снова войти.

## Стек и API

- Интерфейс использует HTML, CSS Grid, Flexbox и JavaScript с DOM, событиями, `fetch` и JSON.
- Express обслуживает статические файлы и REST API. SQLite хранит пользователей, объявления и заявки.
- Пароли хешируются с уникальной солью. Для входа используется cookie с серверной сессией.
- Текст заявки виден только заявителю и автору объявления. Только автор может редактировать или удалять открытое объявление и рассматривать заявки.

| Метод | Маршрут | Действие |
| --- | --- | --- |
| GET | `/api/items` | Получить доску |
| POST | `/api/items` | Опубликовать объявление |
| PATCH, DELETE | `/api/items/:id` | Изменить или удалить своё открытое объявление |
| POST | `/api/items/:id/claims` | Подать заявку |
| GET | `/api/claims` | Получить свои входящие и исходящие заявки |
| PATCH | `/api/claims/:id` | Подтвердить или отклонить входящую заявку |
| GET | `/api/session` | Получить текущий профиль |
| POST | `/api/register`, `/api/login`, `/api/logout` | Управлять входом |
